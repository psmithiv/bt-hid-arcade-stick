Bluetooth HID Arcade Stick
==========================

Welcome to the Sphinx documentation for the Bluetooth HID arcade stick
firmware and companion desktop tools. The documentation is split into
three parts:

.. toctree::
   :maxdepth: 2
   :caption: Contents

   overview
   hardware
   reference

Getting Started
---------------

Clone the repository and set up your CircuitPython board as described in
the :doc:`overview` section. Then build the HTML documentation locally:

.. code-block:: console

   pip install sphinx
   sphinx-build -b html docs build/html

After the build completes, open ``build/html/index.html`` in your browser.
