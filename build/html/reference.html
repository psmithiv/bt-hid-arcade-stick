Firmware Modules¶

Central configuration for the Bluetooth HID arcade stick firmware.

This module centralizes hardware mappings and tunables so they can be adjusted without touching the runtime logic.

All buttons are assumed to be wired active-low with pull-up resistors. Update PIN_MAP with the exact GPIO connections used on the target PCB so the firmware reports the correct button state in hardware and when mirrored through the debug interface.

Firmware entry point for the Bluetooth HID arcade stick.

Initializes every subsystem (BLE, USB, input polling, debugging) and drives the cooperative main loop that runs on the CircuitPython board.

GPIO polling and debouncing for the arcade stick buttons.

Responsible for initializing GPIO inputs and exposing debounced button state changes to upstream consumers. Buttons are assumed to be wired active-low with pull-up resistors; see config for the mapping.

Serial debug protocol for the Bluetooth HID arcade stick.

The debug interface bridges host tooling (such as the virtual controller UI) with the running firmware. Host commands are received over the USB serial console, translated into virtual button events, pairing requests, or log forwards, and the firmware state is mirrored back as structured JSON.
