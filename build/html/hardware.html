Hardware Wiring¶

The firmware assumes the arcade stick buttons are wired active-low with pull-up resistors. Update config.PIN_MAP to match your exact wiring before flashing the firmware.

Pairing Button¶

If you connect a dedicated pairing push-button, configure config.PAIRING_BUTTON_PIN accordingly. The button must be wired active-low; press and hold it for config.PAIRING_HOLD_MS milliseconds to trigger pairing mode. The ble_manager.BLEManager handles debouncing and timeout logic automatically.

Guidelines¶

  • Keep wiring short and avoid sharing grounds across high-current paths.

  • When testing without full hardware, you can temporarily map buttons to the on-board LED or other accessible pins for quick validation.

  • The debug interface mirrors button state back to the host; use the virtual controller UI to confirm wiring changes without rebuilding firmware.
